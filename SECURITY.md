# Security

This is an unaudited pre-release prototype. Report security issues privately to the repository owner through GitHub private vulnerability reporting if enabled, or the professional contact on https://ayush-agrawal.in. Do not post credentials, seed phrases, or private RPC keys in public issues.

Only use trusted RPC endpoints and server-owned invoices. Protect the ledger and backups. Do not treat fixture output as authentic evidence. Do not use this prototype for automatic production order fulfilment until it has undergone independent review and live end-to-end tests.
